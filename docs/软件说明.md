# 灵犀流序（Lingxi Flow）软件说明

> **一句话定位**：自然语言驱动的 AI Agent 个人助理——你开口，AI 动手。
>
> **平台**：HarmonyOS NEXT（API 14+ / SDK 6.1.1）｜ **语言**：纯 ArkTS（约 7500 行，零 JS 桥接）
> **版本**：v1.2 ｜ **状态**：初赛已提交（2026-07-26），复赛冲刺中

---

## 一、产品概览

灵犀流序是一款运行在 HarmonyOS NEXT 上的 AI Agent 应用。与传统语音助手"一问一答"不同，灵犀通过 **ReAct 推理循环**自主规划并执行多步骤任务：用户用自然语言描述目标，AI 自动决定调用哪些系统工具、按什么顺序执行、如何验证结果，最终汇报完成情况。

**示例**：你对灵犀说——

> "查一下杭州的天气，写入一份今日简报，然后提醒我 30 分钟后喝水"

灵犀会依次：查询天气 → 创建今日简报.md → 写入天气内容 → 设置 30 分钟倒计时提醒 → 用关心的语气汇报结果。全程无需你手动切换任何应用。

## 二、核心功能

### 1. AI 对话与任务执行（ReAct Agent）

- **SSE 真流式回复**：AI 回答边生成边显示，体验流畅
- **多轮工具调用**：单次请求内自动编排多个工具（最多 15 轮迭代）
- **多会话管理**：新建 / 重命名 / 删除 / 切换对话，历史持久化，退出重进不丢失
- **断点续传**：任务中途退出后，可带完整上下文继续执行
- **离线兜底**：未配置 API 时自动降级关键词应答，应用始终可用

### 2. 工具系统（22 个本地工具 + MCP 远程工具）

| 领域 | 工具 | 说明 |
|------|------|------|
| 文件 | mkdir / write_file / read_file / list_files / delete_file / search_files / copy_file / paste_file | 沙盒内文件全操作，AI 建的文件在文件管理器立即可见 |
| 提醒 | create_reminder / list_reminders / cancel_reminder | ReminderAgentKit 系统级倒计时，**到点触发、杀进程仍有效**，SQLite 持久化 |
| 时间日期 | get_current_time / get_current_date / get_weekday | 让 AI 具备时间感知 |
| 天气 | get_weather | wttr.in 实时天气 |
| 日历 | calendar_create / calendar_query | 系统日历读写，自动提前 10 分钟提醒 |
| 网页 | web_search / web_fetch | Bing 优先 + DuckDuckGo 兜底（适配国内网络），搜索 + 正文抓取 |
| 记忆 | memory_write / memory_read / memory_list | Markdown 笔记，跨会话长期记忆 |
| 远程 | MCP 客户端（`mcp_` 前缀） | 连接任意 MCP 服务器（Streamable HTTP），接入外部工具生态 |
| 定时任务 | task_create / task_list / task_cancel | 周期/一次性后台 AI 任务（如"每 30 分钟提醒我喝水"） |

### 3. 知识库（RAG 检索增强）

- 自动索引沙盒内 `memory/`、`knowledge/` 目录及根目录文档
- SiliconFlow BGE-M3 向量嵌入 + 余弦检索（未配置嵌入 Key 时自动降级关键词检索）
- 每次对话前检索 top-3 相关内容注入上下文，**让 AI 基于你的资料回答**
- 知识库管理页：查看索引状态、重建、删除文档

### 4. 语音交互

- **语音输入**：SpeechKit 语音转文字，说一句自动填入对话
- **TTS 播报**：每条 AI 回复可一键朗读

### 5. 跨设备协同

- 设备发现（同华为账号 + 组网设备）
- **任务进度实时同步**：手机执行任务，平板/手表实时查看步骤进度
- **提醒分发**：任一设备创建提醒，其他设备同步收到系统通知

### 6. 系统融合

- **小艺意图**：小艺唤起"打开 XX"直达灵犀并自动执行
- **定时提醒**：系统代理提醒（ReminderAgent），锁屏也生效
- **实况窗**（申请审核中）：任务进度与提醒倒计时常驻系统界面

### 7. 体验设计

- 双主题（灵犀浅色 / 龙虾深色）+ 玻璃拟态设计系统
- Markdown 渲染（标题/列表/加粗/行内代码）
- 打字机效果、步骤时间线、执行进度条、完成弹窗

## 三、快速上手

### 1. 安装与配置

| 步骤 | 操作 |
|------|------|
| ① 安装 | 安装 HAP（需 HarmonyOS NEXT 设备） |
| ② 配置 AI | 对话页右上角「API」→ 填入 API 地址 / Key / 模型（兼容 DeepSeek、GLM、Ollama 等任意 OpenAI 兼容服务），建议 `deepseek-chat` |
| ③ 配置嵌入（可选） | 同面板填入 SiliconFlow 嵌入 Key（`BAAI/bge-m3`），解锁语义检索；不填则用关键词检索 |
| ④ 配置 MCP（可选） | 同面板填入 MCP 服务器地址，重启生效，AI 自动获得远程工具 |

### 2. 常用示例

| 你说 | 灵犀会 |
|------|--------|
| "创建一个叫项目的文件夹，里面写个 readme" | 依次调用 mkdir + write_file |
| "30 分钟后提醒我睡觉" | 创建系统倒计时提醒（到点弹通知） |
| "明天下午 3 点开会，安排到日历" | 计算时间 → 创建日历日程（提前 10 分钟提醒） |
| "杭州天气怎么样，顺便记下来" | 查天气 → memory_write 保存 |
| "根据我的笔记，什么是死锁？" | RAG 检索知识库 → 基于笔记回答 |
| "帮我搜一下鸿蒙开发的最新动态" | web_search（Bing）→ 摘要汇报 |
| "1 小时后提醒我喝水"（设备页） | 分发提醒到所有在线设备 |

### 3. 沙盒目录结构

```
/data/storage/el2/base/files/
├── memory/        # AI 记忆笔记（memory_write 写入）
├── knowledge/     # 用户资料（.md/.txt，自动索引进知识库）
├── 任意文件        # 根目录 .md/.txt 也会被知识库索引
└── note.txt       # 示例文件
```

## 四、技术架构

```
用户输入
  → AgentCore（ReAct 循环：Thought → Action → Observation → Answer）
      ├─ ApiClient（OpenAI 兼容 HTTP + SSE 流式，429 重试，流式失败自动回退）
      ├─ ToolRegistry（22 本地工具 + MCP 远程工具，JSON Schema 注册）
      ├─ RagService（BGE-M3 向量检索 / 关键词兜底）
      ├─ McpClient（MCP Streamable HTTP 协议）
      ├─ DatabaseService（SQLite：chats/messages/tasks/workflow_runs/kv）
      └─ DistributedService（设备发现 + 分布式 KV 同步）
  → 事件驱动 UI（AgentEvent 联合类型 → @State 响应式渲染）
```

**关键设计**：

- **工具即插件**：所有系统能力统一抽象为 JSON Schema 工具定义，LLM 通过 Function Calling 自主决策
- **事件驱动**：`text / stream / tool_use / error / done` 五种事件实时注入 ArkUI
- **严格 ArkTS**：零 any/unknown/Record<>，遵循鸿蒙严格模式规范
- **失败隔离**：RAG / MCP / 流式 / 分布式任一环节失败都不影响对话主链路

## 五、隐私与安全

| 项目 | 说明 |
|------|------|
| 数据本地化 | 对话、笔记、知识库、配置全部存储于应用沙盒与本地 SQLite，**无任何云端账号体系** |
| 路径安全 | 所有文件操作经 `resolvePath` 过滤 `../`，防止路径穿越，严格限制在沙盒内 |
| 权限最小化 | INTERNET（对话必需）、通知、麦克风（语音）、日历（日程）、分布式组网（跨设备）——全部按需声明，user_grant 权限弹窗申请 |
| 内存提醒 | 提醒/任务数据持久化在本地，不上传 |
