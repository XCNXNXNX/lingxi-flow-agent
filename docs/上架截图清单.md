# 灵犀流序 AppGallery 上架截图方案

## 规格要求（AppGallery）

- 数量：**6~8 张**（要求 3~10 张）
- 尺寸：**1080 × 1920 px**（宽高比 9:16 竖屏）
- 格式：PNG 或 JPG
- 建议模拟器分辨率调整为 1080×1920（DevEco 模拟器设置里可调），截图即符合尺寸，避免裁剪

## 截图注意事项

1. **隐私安全**：截图前确保页面不出现真实 API Key（密钥输入框留空或用占位符样式截）；对话内容用演示话术
2. **干净整洁**：避免截图出现报错气泡、超时提示、测试垃圾消息；如出现可删掉该轮对话重截
3. **视觉一致**：统一用"龙虾风格"（深色）或"灵犀风格"（浅色）截全套，商店展示更专业（建议深色龙虾风格，更有辨识度）
4. **演示话术**（照着输入即可出漂亮效果）：
   - 新闻："看看今天有什么新闻"
   - 提醒："8:50 提醒我工作"
   - 天气："明天北京天气怎么样"
   - 简报："生成今日简报"
   - 番茄："开始番茄钟"
5. **状态栏**：模拟器状态栏时间/电量为正常值即可，无特殊要求

## 上传位置

- AGC 控制台 → 应用上架 → 商品信息/应用截图 → 上传（可配每张的说明文字）
- 截图建议配 8 张（上限内取满，展示位更饱满）
